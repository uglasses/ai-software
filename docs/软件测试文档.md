# 智能求职平台 — 软件测试文档

## 1. 测试概要

### 1.1 测试目标

- 验证三端核心业务流程（注册登录、岗位浏览、简历上传与匹配、数据分析、后台管理）功能正确。
- 通过自动化测试保障回归，降低发版风险。
- 为项目交付提供可复现的测试证据（命令输出、覆盖率报告、UAT 记录）。

### 1.2 测试范围

| 模块 | 在范围内 | 不在范围内 |
| --- | --- | --- |
| 前端 Vue 3 | 路由、API 封装、页面组件、布局 | 像素级 UI 设计稿比对 |
| 后端 Spring Boot | Controller 切片、Service 单测、集成测、异常处理 | 生产 MySQL 集群压测 |
| ai-service | 规则匹配、技能抽取、健康检查 | 真实大模型推理质量 |
| DeepSeek | HTTP 客户端分支（Mock）、建议服务逻辑 | 配额、内容质量、多轮对话 |
| 性能 | 关键接口 curl 抽样 | 7×24 可用性 SLA、高并发压测 |
| 验收 | 核心功能实现与鲁棒性 | 生产级服务器环境验收 |

### 3.5 CI 持续集成

**配置文件：** [`.github/workflows/test.yml`](../.github/workflows/test.yml)  
**工作流名称：** `CI Tests`  
**触发条件：** 任意 `push`、`pull_request`（同分支重复提交会取消进行中的旧运行）

| Job | 运行环境 | 超时 | 执行命令 | 覆盖用例 |
| --- | --- | --- | --- | --- |
| `Backend (Maven)` | Ubuntu + JDK 17 + Maven 缓存 | 20 min | `mvn -B test` | 71 |
| `Frontend (Vitest)` | Ubuntu + Node 20 + npm 缓存 | 15 min | `npm ci` → `npm test` | 79 |
| `AI Service (pytest)` | Ubuntu + Python 3.11 + pip 缓存 | 10 min | `pip install -r requirements.txt` → `pytest tests -q` | 12 |

**设计要点：**

- 三 job **并行**执行，互不依赖；失败时可在 GitHub **Actions** 页定位到具体端。
- **不调用**真实 DeepSeek API，与本地单测策略一致。
- **不含**覆盖率门禁与 E2E；仅验证三端自动化回归全绿。

**本地预检（推送前）：**

```powershell
cd backend; mvn -B test
cd ..\frontend; npm ci; npm test
cd ..\ai-service; $env:PYTHONPATH="."; .\.venv\Scripts\pytest tests -q
```

**通过标准：** 三个 job 均为绿色。

## 6. 性能测试记录

### 6.1 测试环境

| 项 | 配置 |
| --- | --- |
| 操作系统 | Windows 11 |
| 后端 | Spring Boot，`http://localhost:8080`，H2 + sample 岗位数据 |
| ai-service | FastAPI，`http://localhost:8000` |
| 工具 | PowerShell + `curl.exe`（**须在 PowerShell 中执行**，cmd 不支持 `$times` 等语法） |
| 样本量 | 每场景 **20** 次 |
| 并发 | 串行单请求（非压测） |

### 6.2 执行结果

| 场景 | 方法/路径 | P50 | 阈值 | 结论 |
| --- | --- | --- | --- | --- |
| 岗位列表 | `GET /api/job/list` | 11.6 ms | **14.9 ms** | **通过** |
| 岗位匹配（规则） | `POST http://localhost:8000/ai/job/match` | 209 ms | < 1 s | **通过** |
| 简历 PDF 上传 | `POST /api/resume/upload` | 366.5 ms | < 3 s | **通过** |
| DeepSeek 建议 | 后端 LLM 接口 | 21.9s | <120s | **通过** |

### 6.3 说明与限制

- 结果为**单机开发环境**抽样，不代表生产或多用户并发表现。
- `GET /api/job/list` 走 H2 内存库，生产 MySQL 延迟可能更高。
- 性能测试与 CI **独立**：CI 不跑 curl 抽样，避免依赖长驻服务。
